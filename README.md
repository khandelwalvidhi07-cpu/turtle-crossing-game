# Turtle Crossing Game

This is a Turtle Crossing game I built while learning Python through Angela Yu's 100 Days of Code course.

## How to Play
- Use the Up Arrow key to move the turtle.
- Avoid the cars and try to reach the top of the screen.
- Each successful crossing takes you to the next level, where the cars move faster.
- The game ends if you collide with a car.

## What I Used
- Python
- Turtle module
- Classes and object-oriented programming

## What I Practiced
Working with multiple Python files, creating classes, moving objects on screen, detecting collisions, and managing levels and score.

## How to Run
Run `main.py` using Python 3.
